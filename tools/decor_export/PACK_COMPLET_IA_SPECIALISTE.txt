PACK DE GENERATION D'IMAGES — DECOR DE JEU "MECHA-FORGE"
Destine a une IA specialiste en generation d'images. Lire ENTIEREMENT avant de
generer quoi que ce soit : les regles ci-dessous s'appliquent a CHACUNE des
11 images demandees plus bas.
===============================================================================

CONTEXTE
--------
Ce sont des elements de decor pour un jeu video 2D vu de dessus (top-down),
style action/arcade. Chaque image sera integree telle quelle dans le moteur du
jeu, redimensionnee automatiquement, sans retouche manuelle possible derriere.
C'est pourquoi les regles techniques ci-dessous sont strictes : une image qui
ne les respecte pas ne pourra pas etre utilisee et devra etre regeneree.

===============================================================================
REGLES TECHNIQUES OBLIGATOIRES (lire avant chaque generation)
===============================================================================

1. FORMAT DE SORTIE
   - PNG avec une VRAIE couche alpha transparente (transparence native du
     fichier), PAS un damier gris/blanc dessine, PAS un fond blanc uni, PAS un
     fond d'une autre couleur unie. Le fond doit etre réellement transparent
     au sens informatique du terme (canal alpha = 0 autour du sujet).
   - Resolution minimale conseillee : 1024x1024 pixels (carre). Une image plus
     grande est acceptable, plus petite que 768x768 ne l'est pas.
   - Jamais de JPG (pas de transparence possible dans ce format).

2. CADRAGE ET COMPOSITION
   - UN SEUL objet par image. Jamais de scene, jamais de second plan, jamais
     d'autres objets secondaires autour du sujet principal.
   - Le sujet doit etre CENTRE dans le cadre, avec une marge vide d'environ
     15-20% de chaque cote (haut/bas/gauche/droite). Ne jamais laisser le
     sujet toucher ou depasser les bords de l'image : il sera recadre/redimensionne
     automatiquement et un sujet coupe au bord produira un rendu casse en jeu.
   - PAS de texte, PAS de watermark, PAS de signature, PAS de logo, PAS
     d'interface (pas de barre de vie, pas de HUD, pas de cadre decoratif).
   - PAS d'ombre portee dessinee sous l'objet (le moteur de jeu ajoute sa
     propre ombre automatiquement par-dessus ; une ombre deja presente dans
     l'image créerait un doublon visuel moche).

3. TROIS CATEGORIES D'IMAGES — chaque prompt ci-dessous precise sa categorie,
   le traitement est DIFFERENT selon la categorie :

   CATEGORIE A — "Objet debout" (vue 3/4 plongeante)
     Un objet mecanique/industriel vu depuis au-dessus et legerement de cote,
     comme si on regardait une tourelle ou une machine posee au sol depuis un
     point de vue en hauteur a ~45-60 degres. L'objet a du VOLUME (hauteur
     visible), pas juste une forme plate.

   CATEGORIE B — "Danger de sol" (vue du dessus, quasi a plat)
     Un element qui est au RAS DU SOL (une flaque, une plaque de glace, un
     trou, une grille) : pas de volume vertical important, vu presque
     perpendiculairement depuis au-dessus, comme un decalque pose sur le sol.
     Ne pas dessiner de perspective 3/4 pour ces elements-la : c'est plat.

   CATEGORIE C — "Texture de sol" (uniquement pour les textures, aucune ici)
     Non applicable a ce pack (les 4 textures de sol ont deja ete generees
     separement). Ignorer cette categorie pour ce pack-ci.

4. STYLE VISUEL A RESPECTER SUR TOUTES LES IMAGES
   - Rendu "concept-art peint numeriquement", PAS photorealiste, PAS
     cartoon/chibi, PAS pixel-art.
   - Eclairage directionnel doux venant du HAUT-GAUCHE sur chaque image (pour
     que toutes les images aient une direction de lumiere coherente entre
     elles une fois mises cote a cote dans le jeu).
   - Silhouette nette et lisible, meme en tres petit (l'image sera affichee a
     une taille reduite dans le jeu — evitez les details fins qui
     disparaitraient en miniature).
   - Finition "science-fiction industrielle" : metal, panneaux, rivets,
     tuyaux, lumieres neon/emissives selon la couleur precisee dans chaque
     prompt.
   - Une image de reference de style est jointe a ce pack
     (reference_style.png) : si votre outil accepte une image de reference,
     joignez-la systematiquement pour les images de CATEGORIE A (objets
     debout). Elle n'est pas necessaire pour les images de CATEGORIE B.
     DESCRIPTION DE LA REFERENCE (si vous ne pouvez pas charger le fichier) :
     une tourelle de defense industrielle, vue 3/4 plongeante, metal gris-bleu
     acier avec rivets et panneaux, rendu peint numerique avec ombres douces,
     silhouette tres nette, fond entierement transparent.

5. COULEURS — respecter STRICTEMENT la couleur d'accentuation indiquee dans
   chaque prompt (cyan electrique, orange avertissement, dore, etc.) : c'est
   le code couleur qui permet au joueur d'identifier le type de danger en un
   coup d'oeil dans le jeu. Ne pas improviser une autre couleur d'accent.

6. NOMMAGE DES FICHIERS EN SORTIE — merci de nommer chaque image exactement
   comme indique entre crochets [nom_fichier.png] au debut de chaque prompt
   ci-dessous, pour que l'integration dans le jeu soit directe.
