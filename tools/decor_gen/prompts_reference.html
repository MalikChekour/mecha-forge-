Règle à répéter sur CHAQUE prompt de décor (pas les textures de sol)

  • Joins l'image game/assets/decor/g27.png comme référence de style dans Antigravity avant de coller le prompt.
  • Vue 3/4 en plongée (comme une tourelle vue depuis au-dessus), rendu peint numérique, pas photoréaliste.
  • Fond entièrement transparent, pas d'ombre portée intégrée, pas de texte, pas de watermark.
  • Objet unique, centré, silhouette nette — c'est une icône de jeu, pas une illustration de scène.
