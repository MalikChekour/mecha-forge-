VFX animés — ce que je sais faire

20 effets, générés en procédural (numpy/scipy), tous styles confondus. Chacun est une planche de sprites prête pour le jeu (fond noir = fusion additive, boucle propre). Zéro asset externe, zéro crédit, 100 % paramétrable.

Réaliste

Boule de feu

fireball

turbulence + rampe de chaleur, noyau blanc

Jet de flamme

fire_jet

cône de feu bruité, dirigé

Gerbe d'étincelles

sparks

particules physiques + gravité

Fumée

smoke

bruit gaussien qui monte et se dissipe

Anime / stylisé

Impact anime

anime_impact

étoile 6 branches + noyau, punch net

Coup tranchant

slash

arc de lame qui balaie

Nova

nova

rayons radiaux + anneau qui s'étend

Élémentaire

Éclair

Givre

frost

Magie / Sci-fi

Rayon

Soin

Pixel / digital

Explosion pixel

pixel_explosion

rétro, palette 4 couleurs, blocs

Glitch holo

scanlines + décalage RVB

Implosion

implosion

particules aspirées + flash final

Chaque effet = ~40 lignes de code que je peux régler à l'infini : couleur, vitesse, taille, nombre d'images, direction.
Dis-moi lesquels tu veux dans le jeu (et pour quoi : tir, mort d'ennemi, level-up…) et je les câble — ou je t'en fabrique de nouveaux sur mesure.
