Real Robot — choix pour Meshy

Verifie independamment : les 6 passent le test de separation des membres (bras detaches du torse, jambes separees), fond gris uni, rien de coupe au bord.
Toutes les armes sont dans les avant-bras ou sur les epaules — jamais tenues en main. Aucune antenne en V, aucun design de franchise.

RIG OK

R1ASTRAEA

🔫 Canon d'energie dans CHAQUE avant-bras

Blanc perle / azur — le classique elance. Deux canons integres aux avant-bras : le rig les suivra et me donnera deux ancrages de canon symetriques pour le flash.

RIG OK

R2TEMPEST

🔫 2 canons d'epaule + canon avant-bras

Ardoise / cramoisi — canonnier lourd. Les canons d'epaule sont boulonnes aux pauldrons : zero risque de fusion, et une silhouette qui impose.

RIG OK

R3SABLE

🔫 Railgun long le long de l'avant-bras

Noir mat / violet — sniper. Bande optique horizontale au lieu de deux yeux. Le railgun depasse le poing : ancrage de canon tres net.

RIG OK

R4AURORA

🔫 Emetteurs de poignet + pods d'epaule

Ivoire / champagne — elegant. Sac dorsal en blocs epais (pas d'ailettes fines) : concu pour survivre au remesh.

RIG OK

R5RONIN

🔫 Canon a dispersion + lance-missiles d'epaule

Rouge laque / noir — samourai. Pauldrons evases en plaques epaisses, jupe blindee qui degage les jambes.

RIG OK

R6HERALD

🔫 2 autocanons d'avant-bras + pod capteur

Vert sarcelle / blanc casse — soutien. Volumes boxy et trapus = le plus facile a reconstruire proprement en 3D.

Ma reco : R1 ASTRAEA (deux canons symetriques = deux ancrages parfaits pour le flash) ou R6 HERALD (volumes trapus = la reconstruction 3D la plus propre).
Le plus badass : R5 RONIN. Le plus original : R3 SABLE.
